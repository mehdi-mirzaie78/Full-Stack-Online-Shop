### Scope and security contract

“Track everything” means useful events at failure boundaries, not recording every input. Never log bodies, query strings, cookies, authorization, IP addresses, phone/email, payment tokens, presigned URLs, SQL, task args/kwargs/results, arbitrary exception messages, exception locals, or entire request/response objects. Do not blanket-monkeypatch `console`, `fetch`, ORM, or every function.

Schema: UTC `timestamp`, uppercase `level`, `service`, `logger`/`event`, nullable `request_id`/`task_id`, plus explicitly permitted metadata. Python exceptions include type and bounded file/function/line frames, **not exception text or source lines**. This intentionally trades some debugging detail for a defensible default against secret leakage. Frameworks may still emit native diagnostics outside these handlers; no claim of universal redaction.

No Sentry/Datadog/Loki/OpenTelemetry infrastructure, shipping endpoint, credentials, admin audit model, deployment automation, or alerting in this slice. Native container service logs remain available through Compose. Remote browser history, cross-device search, alert delivery and durable retention are explicitly not delivered by stdout/browser console alone.

```python
import json
import logging
import traceback
from contextvars import ContextVar
from datetime import UTC, datetime
from pathlib import Path
from uuid import UUID, uuid4

request_id: ContextVar[str | None] = ContextVar("request_id", default=None)
EVENTS = {"http_request", "database_unavailable", "redis_unavailable", "cache_mismatch"}


def correlation_id(value: object) -> str:
    try:
        return str(UUID(str(value)))
    except (ValueError, TypeError, AttributeError):
        return str(uuid4())


class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        from celery import current_task

        task = current_task
        task_request = getattr(task, "request", None)
        task_headers = getattr(task_request, "headers", None) or {}
        event = getattr(record, "event", "framework_log")
        data = {
            "timestamp": datetime.fromtimestamp(record.created, UTC).isoformat(),
            "level": record.levelname,
            "service": "celery" if getattr(task_request, "id", None) else "django",
            "logger": record.name,
            "event": event if event in EVENTS else "framework_log",
            "request_id": request_id.get() or task_headers.get("request_id"),
            "task_id": getattr(task_request, "id", None),
        }
        if event == "http_request":
            for key in ("method", "route", "status_code", "duration_ms"):
                data[key] = getattr(record, key, None)
        if record.exc_info and record.exc_info[0]:
            frames = traceback.extract_tb(record.exc_info[2])[-15:]
            data["exception"] = {
                "type": record.exc_info[0].__name__,
                "frames": [{"file": Path(f.filename).name, "line": f.lineno,
                            "function": f.name} for f in frames],
            }
        return json.dumps(data, ensure_ascii=True)
```

```python
import logging
from time import perf_counter

from django.http import HttpRequest, HttpResponse

from apps.core.logging import correlation_id, request_id

logger = logging.getLogger("apps.core.http")


class RequestLoggingMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request: HttpRequest) -> HttpResponse:
        identifier = correlation_id(request.headers.get("X-Request-ID"))
        token = request_id.set(identifier)
        started = perf_counter()
        status = 500
        try:
            response = self.get_response(request)
            status = response.status_code
            response["X-Request-ID"] = identifier
            return response
        finally:
            match = getattr(request, "resolver_match", None)
            route = getattr(match, "route", None) or "unmatched"
            logger.log(logging.ERROR if status >= 500 else logging.INFO,
                       "http_request", extra={
                           "event": "http_request", "method": request.method,
                           "route": route, "status_code": status,
                           "duration_ms": round((perf_counter() - started) * 1000, 2),
                       })
            request_id.reset(token)
```

type Event = "request_failed" | "browser_error" | "unhandled_rejection" | "render_failed" | "preview_failed";
type Context = { service?: "next" | "browser"; requestId?: string; route?: string; method?: string };
const uuid = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export function reportError(event: Event, error: unknown, context: Context = {}) {
  console.error(JSON.stringify({
    timestamp: new Date().toISOString(),
    level: "ERROR",
    service: context.service ?? "browser",
    event,
    error_type: error instanceof Error ? error.name : "UnknownError",
    request_id: context.requestId && uuid.test(context.requestId) ? context.requestId.toLowerCase() : null,
    route: context.route ?? null,
    method: context.method ?? null,
  }));
}

## Risks, tradeoffs, open questions

1. **Remote monitoring destination:** user has not chosen managed Sentry/error tracking or self-hosted log store. Current slice gives safe local/server logs + CI, not always-on centralized browser reporting. Ask before adding external transmission, costs, retention or credentials.
2. **Intentionally reduced exception detail:** exception values/stack source lines can contain secrets. Safe frame/type data helps locate code but may not explain provider response. Add narrowly reviewed error codes later, never enable blanket payload logging.
3. **Framework-native diagnostics:** Next/Celery/other libraries may print native errors outside custom reporter. Test actual development/production output before claiming confidentiality; avoid real credentials in error probes. Full native-output sanitization is a separate design, not a claim this formatter can guarantee.
4. **Cross-layer trace continuity:** no existing Next API client to instrument. Django IDs and Celery headers work; Next/browser records do not magically become one distributed trace. Add propagation when first real API loader is introduced, with CORS allowed/exposed header tests if browser cross-origin correlation is needed.
5. **No logging service retention:** Compose logs are ephemeral/engine-managed; no uptime alerting. Decide collector and retention before production. Do not add a big observability stack to scaffolding by default.
6. **Real worker/storage probes:** no business tasks or storage use-case tests yet. Keep RabbitMQ/SeaweedFS outside initial CI until boundaries exist; no fake success or eager-mode broker claims.
7. **Coverage baseline:** target is existing 85% runtime apps contract. Actual baseline was not executed during planning; if insufficient, add focused missing behavior tests, never lower threshold silently. Client coverage reporting/threshold remains TASK-701 rather than inventing a percentage.
8. **Dependency/runtime drift:** Actions runners, browsers, service image tags and Python lock availability may drift. npm/Python lockfiles are source of truth; refresh only when install incompatibility is proven. No broad upgrades bundled here.
9. **Branch ancestry:** current foundations may not be in develop. Choose correct implementation base before editing; no history rewrite or unrelated cherry-picks by guess.
10. **Test artifacts:** traces may capture page content; synthetic test data only, short retention, no production credentials. Do not upload root `.env`, raw environment dumps, or secret-bearing application logs.
